# RedCraft

## About
This mod adds new ores, blocks, armor, and cats.

## Installation
> Dependency forge 1.12.2

Download/build .jar.

Move file in  "mods" folder.


## Build

>need jre 1.8 SDK

Clone repository, open from inteleji idea.

Start "runClient"

Builded jar will be located in 

```
/build/reobfjar/*
```
